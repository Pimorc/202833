These are materials for 202833 class. The number of classes is 14 classes. Each class is 1.5 hours. In total 21 hours of practice session.

## Six folders of materials
One folder for ppt slides
One folder for the term project
Four folders for the worksheets

## Class structure
1. R intro and 2 basic worksheet = one R intro ppt slide set and two worksheet for 2-3 classes depending on students' progress
2. Exploratory data analysis = two worksheet for two classes
3. Hypothesis testing = one big worksheet for 5-6 classes
4. Multivairate data analysis = two ppt slide set and one worksheet for 2-3 classes
5. Allocate one class for students to work on their term project.

## Grading scheme
Exercise 25% (each worksheet contain an 10-point homework execise) 
Term project 25% (Raw points for the project is 30 points)

Students have one week to finish their homework exercise
